# Contributing to Ferrium

Thank you for your interest in contributing to **Ferrium**!

## Development Setup

```bash
git clone https://github.com/Kirieshka14/ferrium.git
cd ferrium
cargo test --workspace
```

## Running Ferrium

- **Studio IDE**: `./run.sh editor`
- **Standalone Engine**: `./run.sh game`
- **Headless Smoke Test**: `./run.sh headless`

## Commit Convention

We follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat(scope): ...`
- `fix(scope): ...`
- `refactor(scope): ...`
- `test(scope): ...`
- `docs(scope): ...`
- `chore(scope): ...`
